# Arquitectura (versión simple)

## Dos carpetas distintas
1. **Command Center** (`C:\dev\command-center`) — notas, `.md`, playbook. No es el producto.
2. **Proyecto real** (`C:\dev\projects\<slug>` o `htdocs\<slug>`) — aquí vive el código.

## Flujo
Reunión → preguntas → respuestas → `.md` pactado → **Cursor codea por bloques** → Iván prueba en PC → “sigue” → hasta terminar.

App HTML / JSON / merge = **opcional**. No bloquean el avance.

## Checks
Significan: “haz/mira esto en el proyecto real”. No son un semáforo que frene a la IA.
