Objetivo: preparar la prueba técnica presencial de **4 horas** alineada con la vacante LinkedIn:

> Diseñar, desarrollar, mantener y mejorar sistemas institucionales…  
> con seguridad, control de cambios, trazabilidad y protección de información.

## Formato probable del día (lectura realista)

La citación es en **Aula de Informática L-1-4**. Eso casi siempre significa:

| Escenario | Probabilidad | Qué esperar |
|---|---|---|
| Computador del aula + enunciado PDF/Word | Alta | Java, SQL en cliente, tal vez Tomcat/DB |
| Computador + hoja impresa de enunciado | Alta | Entregas en carpeta / Word / PDF / código |
| Solo papel (sin PC) | Baja | Más análisis; menos probable en aula de informática |
| Tu propio portátil | Media-baja | Solo si lo anuncian |

**Conclusión práctica:** prepárate para **PC con entorno Java + SQL**. Lleva lápiz/papel para bocetar. Confirma al llegar: JDK, IDE, Oracle/Postgres, Tomcat, carpeta de entrega.
